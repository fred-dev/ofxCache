# ofxCache
A sophisticated, yet easy-to use cascading caching framework for openFrameworks.

Caches values in layers (memory, then disk or other stores), checking each layer in turn and filling the faster ones on a miss. Header only; see `tests/` for usage.

> **About this fork:** fork of [bakercp/ofxCache](https://github.com/bakercp/ofxCache). This branch matches upstream. The `poco_headers_only` branch builds against [ofxPocoHeaders](https://github.com/fred-dev/ofxPocoHeaders) instead of the old ofxPoco addon.
